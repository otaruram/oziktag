# Direktori Konteks Proyek (Oziktag)

Folder ini (`docs/context/`) didedikasikan khusus untuk Anda menyimpan berbagai file referensi, aturan desain, *guideline*, atau materi *pitching* agar tidak berantakan di folder utama.

**Cara Penggunaan:**
- Anda bisa melempar file-file PDF, dokumen Markdown (`.md`), atau catatan *brainstorming* ke dalam folder ini.
- AI (saya) akan secara otomatis bisa membaca konteks dari folder ini jika Anda meminta saya mereferensikan "konteks desain" atau "aturan proyek".

**File yang disarankan untuk ditaruh di sini:**
1. `desain.md` / `ui_ux_rules.md` - Aturan warna, font, dan komponen frontend.
2. `database_schema.md` - Catatan struktur database.
3. `pitch_deck_notes.md` - Catatan untuk BNI Spark Arc.
